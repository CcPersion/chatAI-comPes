## 项目名称

local-ai-companion-v2（本地 AI 赛博女友 v2）

## 一句话描述

Windows 本机运行的 Web 端 AI 语音伴侣：用户通过浏览器文字/语音聊天，系统在 WSL2 内完成语音识别、大模型对话、声音克隆语音合成、wav2lip 实时口型驱动，并通过 LiveTalking WebRTC 将数字人画面低延迟推送到浏览器。

## 技术偏好

- **运行环境**：WSL2 Ubuntu 24.04（AI 链路）+ Windows 原生（llama.cpp 大模型可选）
- **大模型**：llama.cpp + Qwen3-14B-Instruct-Q4_K_M（16GB 显存）或 Qwen3-8B 降级
- **语音识别**：faster-whisper large-v3
- **语音合成**：Qwen3-TTS 1.7B + 声音克隆
- **口型同步**：wav2lip256 + LiveTalking（WebRTC 推送）
- **前端 UI**：Gradio（speech-to-speech 自带），后续可升级定制 React
- **数字人底图生成**：ComfyUI + Wan2.2（一次性操作）
- **编排脚本**：Bash (.sh) + Windows Batch (.bat) 一键启动

## 约束条件（不可改变）

1. **100% 本地运行**：不调用 OpenAI/D-ID/HeyGen 等任何云端推理接口
2. **断网可用**：首次下载模型和依赖后，可完全离线运行
3. **目标硬件**：NVIDIA RTX 5060 Ti 16GB 显存 / 16GB 系统内存 / SSD
4. **单用户单角色**：首版只支持一个会话、一个数字人
5. **页面简洁**：只显示数字人画面、语音球、聊天记录、输入框、麦克风、停止按钮；不展示调试/情绪/参数面板
6. **写实女性**：非二次元、非卡通、非静态头像配音
7. **不用预录视频**：口型由 wav2lip256 实时音频驱动，不用状态切换预录片段
8. **技术栈固定**（零度方案已验证）：llama.cpp, faster-whisper, Qwen3-TTS, wav2lip256, LiveTalking, WSL2
