覆盖 PRD 全部 10 条验收标准 (AC-01 ~ AC-10)，以及架构设计中的 8 条适用安全规则 (SEC-02/03/04/05/11/12/17/18)。

## 2. 测试方法

### 2.1 静态分析（可执行，本报告产出）

- **代码结构完整性**: 验证 app.py 中所有声称的类/函数/模块实际存在，并与 API契约.md 声明的接口对应。
- **安全合规检查**: 逐条验证 SEC-02/03/04/05/11/12/17/18 在代码中的实现。
- **API契约符合性**: 检查 app.py 实现的接口是否匹配 API契约.md 定义的端点、错误码、请求/响应格式。
- **配置完整性**: voice.yaml 是否覆盖 API契约 §4.6 所有配置项。
- **依赖审计**: requirements.txt 的依赖是否有已知风险。
- **脚本逻辑审查**: 启动/停止/安装脚本的正确性与边界条件。

### 2.2 功能验证（需 WSL2 + GPU 环境，本报告仅设计用例）

- **全链路端到端测试**: 麦克风输入 -> VAD -> ASR -> LLM -> TTS -> 音频播放 + 口型驱动
- **首响延迟测量**: 使用系统时间戳精确测量各阶段延迟
- **打断时序验证**: 使用毫秒级计时验证音频在 500ms 内停止
- **显存占用监控**: 使用 nvidia-smi 持续监控运行全程
- **音色克隆主观评测**: 3 人盲评，AB 测试

## 3. 测试环境要求

### 硬性要求（实机运行时）
- Windows 10/11 + WSL2 Ubuntu 24.04
- RTX 5060 Ti 16GB 显存 / 16GB 系统内存 / SSD
- CUDA 12.x + WSL2 GPU 透传
- Chrome/Edge 最新稳定版
- 大模型文件: Qwen3-8B-Instruct-Q4_K_M.gguf (~6GB)
- faster-whisper large-v3 模型文件 (~3GB)
- Qwen3-TTS 1.7B 模型文件 (~4GB)
- wav2lip256.pth 权重文件
- idle.mp4 底版视频

### 本次静态分析环境
- Windows 10 Pro x64
- Python 3.x (仅用于代码阅读，不运行)
- 无 WSL2 / GPU / CUDA 环境

## 5. 风险与限制

### 当前环境限制
- **无法在纯 Windows 环境实际运行 WSL2 脚本**: .sh 脚本无法执行，但可进行逻辑审查
- **无法加载真实模型**: 需 GPU + 大模型文件（Qwen3-8B ~6GB 等），当前环境无
- **无法验证实时音频链路**: VAD / ASR / TTS 需要硬件与模型
- **无法验证 WebRTC 视频流**: 需要 LiveTalking + wav2lip256 运行环境
- **无法进行主观音色评测**: AC-05 需要 3 人盲评

### 静态分析覆盖度评估
- **可完整验证**: 代码结构、安全合规、API契约符合性、配置完整性、错误码覆盖
- **可逻辑分析**: 打断控制流、状态机转换、对话历史管理、流式拆句策略
- **仅有理论支撑**: 首响延迟、显存实际占用、音色克隆主观质量、口型同步偏差

## 6. 测试通过标准

- **静态分析**: 所有适用 SEC 规则通过或有不适用说明；API 契约接口 100% 有对应实现；配置项 100% 覆盖；无 P0/P1 未修复 Bug。
