# 项目方案 (v1 弃用)

## 架构

- `apps/web`：React 前端，显示写实女性视觉层、聊天记录、输入框、麦克风、发送和停止按钮。
- `apps/orchestrator`：Node.js 本地协调服务，提供健康检查、Ollama 流式聊天、ASR/TTS/轻量视觉层适配器入口和取消控制。
- `scripts/dev.mjs`：一键启动前端与后端。
- `docs`：权威目标、方案、状态、安装运行说明和本地服务说明。

## 分阶段计划

1. 阶段 1：本地基础闭环
   - React 页面可运行。
   - 本地协调服务可运行。
   - Ollama 真实流式回复。
   - 1B-lite 先接入写实女性视觉占位/轻量 talking head，不再阻塞于 Unreal。
2. 阶段 2：本地语音与打断
   - 接入 SenseVoice 或 Whisper 本地 ASR。
   - 接入 CosyVoice 或 Qwen3-TTS 本地 TTS。
   - 短句级播放与停止取消。
3. 阶段 3：真人感联动
   - 后端向轻量视觉层推送状态、情绪、音频和口型/表情参数。
   - 视觉层完成待机、倾听、思考、说话状态机。
   - 连续三轮人工验收不崩溃、不串音、不串状态。
4. 后续升级：3D 真人数字人
   - 在轻量闭环稳定后，再恢复 Unreal + MetaHuman + Pixel Streaming 路线。
   - 3D 升级必须单独验收，不能由 1B-lite 自动继承。

## 当前技术决策

- 前端用 React + Vite，降低本地开发复杂度。
- 后端用 Node.js 原生 HTTP 和 Fetch，减少协调服务依赖。
- Ollama 采用 `/api/chat` 流式 NDJSON。
- 当前阶段从 Unreal/MetaHuman 降级为 `1B-lite`：优先跑通本地 speech-to-speech 和轻量视觉层，再做 3D 升级。
