## 最终目标

先在 Windows 本机运行一个 Web 端本地 AI 语音伴侣：浏览器负责文字/语音交互和显示写实女性视觉形象，本地后端编排 Ollama、ASR、TTS 与轻量视觉层。第一版优先跑通完整本地 speech-to-speech 闭环；Unreal + MetaHuman + Pixel Streaming 保留为后续 3D 升级目标。

## 不可改变的约束

- Web 端本机浏览器访问。
- 核心推理本地运行，不依赖 OpenAI、D-ID、HeyGen 等付费云端推理接口。
- 大模型使用 Ollama 中文开源模型，首版优先 7B 至 8B 4-bit。
- ASR 优先使用 SenseVoice 或 Whisper，TTS 优先使用 CosyVoice 或 Qwen3-TTS，按本机可运行性选择。
- 第一版视觉层降级为写实女性图像/轻量 talking head；后续再升级 Unreal Engine + MetaHuman 或同等级真人 3D 资产。
- 不用云端推理接口、二次元 Live2D 或模拟接口代替真实功能验收。
- 若采用静态图或轻量 talking head，必须明确标记为 `1B-lite`，不得宣称已完成 Unreal/3D 数字人验收。
- 页面保持简洁，不展示情绪面板、模型参数面板或调试面板。

## 验收边界

自动测试只能证明后端编排、状态机、错误处理和前端构建；不能替代真人麦克风、TTS 听感、轻量视觉口型/表情的人眼验收。`1B-lite` 通过不等于 Unreal/MetaHuman/Pixel Streaming 通过。
