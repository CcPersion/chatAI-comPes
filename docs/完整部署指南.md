# 完整部署指南 — local-ai-companion-v2

> 目标：将所有功能（LLM 对话 / ASR 语音识别 / TTS 语音合成 / 数字人口型驱动）在 WSL2 + Windows 环境下全部跑通。

---

## 架构速览

```
Windows 侧                        WSL2 侧
┌─────────────────┐              ┌──────────────────────────────────┐
│ Ollama :11434    │◀──HTTP──────│ speech-to-speech 管线 :7860      │
│ (qwen2.5:7b)     │              │  VAD → ASR → LLM转发 → TTS     │
└─────────────────┘              │                │                 │
                                 │    ┌───────────┼───────────┐     │
                                 │    ▼           ▼           ▼     │
                                 │ 浏览器     avatar-sync  LiveTalk │
                                 │ :7860      :8011        :8010    │
                                 │ (用户界面) (音频转发)  (口型驱动) │
                                 └──────────────────────────────────┘
```

**启动顺序**：Ollama → WSL2安装依赖 → LiveTalking → avatar-sync → Gradio管线

---

## 第一步：Windows 侧 — 确保 Ollama 就绪

你已有 `qwen2.5:7b-instruct`，确认服务运行中：

```powershell
# 验证 Ollama 正常
curl http://127.0.0.1:11434/api/tags
```

> **可选替代方案**：如果你想按原架构用 llama.cpp server（性能更好、显存管理更强），需要下载：
> - `llama-server.exe` → https://github.com/ggerganov/llama.cpp/releases
> - `Qwen3-8B-Instruct-Q4_K_M.gguf` → HuggingFace
>
> 然后用 `scripts/start-llama.bat` 启动在 `:8090`，同时修改 `voice.yaml` 中 `LLM_BASE_URL` 为 `http://localhost:8090`。
>
> **当前直接用 Ollama 也可以，voice.yaml 已配好。**

---

## 第二步：WSL2 侧 — 环境准备

进入 WSL2：

```powershell
wsl
```

### 2.1 确认 GPU 透传

```bash
nvidia-smi
```

如果报错 `command not found` 或看不到 GPU，说明 WSL2 GPU 透传未配置。需要：
1. Windows 侧安装 NVIDIA 驱动（支持 WSL2 的版本）
2. WSL2 内安装 CUDA toolkit（非必需但建议）

### 2.2 将项目复制到 WSL2

```bash
cp -r /mnt/d/codexWorkSpec/chatAI-comPes ~/chatAI-comPes
cd ~/chatAI-comPes
```

### 2.3 运行安装脚本

```bash
chmod +x scripts/install-voice.sh
bash scripts/install-voice.sh
```

这个脚本会：
1. 检查 CUDA / GPU 显存
2. 创建 `~/setup/` 目录结构
3. 创建 Python 虚拟环境 `~/setup/venv/`
4. 安装所有 Python 依赖（`outputs/backend/requirements.txt`）
5. 下载模型：
   - `faster-whisper-large-v3`（~3GB）→ `~/setup/models/faster-whisper-large-v3/`
   - `Qwen3-TTS-1.7B`（~4GB）→ `~/setup/models/Qwen3-TTS-1.7B/`
6. 复制 `scripts/` 和 `config/voice.yaml` 到 `~/setup/`
7. 校验关键文件

**首次下载模型需要联网，约需下载 7GB+ 数据。**

## 第三步：获取运行时资产

以下 3 个文件必须手动获取并放到 `~/setup/`：

### 3.1 `wav2lip256.pth` — 口型驱动权重

来源：wav2lip256 项目（参考零度解说 2026-08-03 教程）

```bash
# 通常从 Google Drive / 百度网盘下载
# 下载后放入：
cp /mnt/d/path/to/wav2lip256.pth ~/setup/
```

### 3.2 `idle.mp4` — 数字人底版视频

用 ComfyUI + Wan2.2 一次性离线生成（不需要常驻运行）。

规格要求：
- 分辨率：704×896（竖屏）
- 时长：5 秒
- 内容：写实女性、闭嘴、眨眼、轻微呼吸
- 一次性操作，生成后 ComfyUI 可关闭/卸载

```bash
cp /mnt/d/path/to/idle.mp4 ~/setup/
```

> 如果没有 ComfyUI + Wan2.2 环境，可以先放一个占位视频测试链路通畅，之后再替换。

### 3.3 `ref.wav` — 音色克隆参考音频

5-15 秒清晰单人女声录音（wav 格式，16kHz 单声道最佳）。

```bash
cp /mnt/d/path/to/ref.wav ~/setup/
```

> 也可以通过浏览器在 Gradio 页面上传（"音色克隆设置"面板）。

## 第四步：配置 voice.yaml

WSL2 内编辑 `~/setup/voice.yaml`，关键配置项：

```yaml
# ---- LLM ----
LLM_BASE_URL: "http://localhost:11434/v1"   # Ollama（Windows 侧）
LLM_MODEL: "qwen2.5:7b-instruct"            # 你已有的模型
LLM_MAX_TOKENS: 1024
LLM_TEMPERATURE: 0.7

# ---- ASR ----
ASR_MODEL: "large-v3"
ASR_LANG: "zh"

# ---- TTS ----
TTS_MODEL_PATH: "~/setup/models/Qwen3-TTS-1.7B"
TTS_REF_WAV: "~/setup/ref.wav"
TTS_SAMPLE_RATE: 16000

# ---- LiveTalking ----
LIVETALKING_URL: "http://localhost:8010"
AVATAR_SYNC_URL: "http://localhost:8011"

# ---- 系统 ----
LOG_DIR: "~/setup/logs"
UPLOAD_DIR: "~/setup/uploads"
```

> ⚠️ **注意**：app.py 的健康检查会访问 `{LLM_BASE_URL}/health`，但 Ollama 没有这个端点。这不影响实际对话功能，只是"连接状态"面板会显示 LLM 为 disconnected。如果介意，需要改用 llama.cpp server（见第一步可选项）。

## 第五步：启动！

严格按顺序启动，每个就绪后再启动下一个。

### 5.1 Windows 侧：Ollama（已运行则跳过）

```powershell
ollama serve
```

### 5.2 WSL2 侧：LiveTalking（数字人口型）

```bash
cd ~/setup
bash start-livetalking.sh
```

轮询等待 `http://127.0.0.1:8010/health` 返回 200。

### 5.3 WSL2 侧：avatar-sync（音频转发桥接）

```bash
cd ~/setup
# 先安装 Node.js 依赖（仅需 ws）
sudo apt install nodejs npm -y
npm install ws

# 启动
node avatar-sync.js &
```

轮询等待 `http://127.0.0.1:8011/health` 返回 200。

### 5.4 WSL2 侧：Gradio 主应用

```bash
cd ~/setup
source venv/bin/activate
bash start-voice.sh
```

轮询等待 `http://127.0.0.1:7860/` 返回 200。

## 常见问题

### Q: LiveTalking 启动失败？
A: 确认 `~/setup/wav2lip256.pth` 和 `~/setup/idle.mp4` 存在。LiveTalking 的具体启动命令取决于你获取的版本（零度教程方案），`start-livetalking.sh` 中的入口文件路径需要按实际情况调整。

### Q: ASR 模型下载失败？
A: 手动下载：
```bash
huggingface-cli download Systran/faster-whisper-large-v3 --local-dir ~/setup/models/faster-whisper-large-v3
```

### Q: TTS 模型下载失败？
A: 手动下载：
```bash
huggingface-cli download Qwen/Qwen3-TTS-1.7B --local-dir ~/setup/models/Qwen3-TTS-1.7B
```

### Q: 显存不够（16GB 卡跑全部组件）？
A: 
- 使用 8B 模型（Ollama 的 qwen2.5:7b 约占 5-6GB）
- 串行加载组件，关掉不用的
- 架构设计预估全部常驻 ~14GB，处于上限边缘

### Q: WSL2 访问不了 Windows 的 Ollama？
A: 在 WSL2 内测试：
```bash
curl http://localhost:11434/api/tags
```
如果不通，检查 Windows 防火墙是否拦截了 WSL2 的 localhost 转发。或者改用 Windows 主机 IP（在 WSL2 内 `cat /etc/resolv.conf` 看 nameserver 地址）。
