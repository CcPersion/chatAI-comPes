# 安装与启动 (v1 弃用)

## 环境检查结果

- Node.js：已检测到 `v24.13.0`
- npm：已检测到 `11.6.2`
- Python：已检测到 `3.14.2`
- Ollama HTTP：`http://127.0.0.1:11434` 可访问
- 本地模型：`qwen2.5:7b-instruct`，7.6B，Q4_K_M
- Unreal：当前未在 PATH 中检测到 `UnrealEditor.exe`

## 安装

```powershell
npm.cmd install
```

## 启动

```powershell
npm.cmd run dev
```

默认地址：

- Web：`http://127.0.0.1:5173`
- 后端：`http://127.0.0.1:3100`
- 后端健康检查：`http://127.0.0.1:3100/api/health`

## 本地服务

- Ollama：必须先启动并监听 `127.0.0.1:11434`。
- Unreal Pixel Streaming：默认页面为 `http://127.0.0.1:80`，可通过 `PIXEL_STREAMING_URL` 修改。
- SenseVoice：阶段 2 启用，设置 `ASR_ENABLED=true` 和 `ASR_ENDPOINT`。
- CosyVoice：阶段 2 启用，设置 `TTS_ENABLED=true` 和 `TTS_ENDPOINT`。
